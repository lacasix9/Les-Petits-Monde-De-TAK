# Les Petits Monde De TAK — projet Android V2 (base de compilation)

## Compilation avec GitHub Actions
1. Décompresser cette archive.
2. Envoyer **le contenu** de ce dossier à la racine du dépôt GitHub (les dossiers `app` et `.github` doivent être visibles à la racine).
3. Ouvrir l'onglet **Actions** puis lancer **Android APK** (ou pousser un commit sur `main`).
4. Une fois le workflow terminé, ouvrir son exécution et télécharger l'artefact `Les-Petits-Monde-De-TAK-APK`.

Le workflow installe Gradle 8.10.2 lui-même : aucun fichier `gradlew` n'est requis.

## Contenu actuel
Cette archive reprend la V1 jouable : univers maternelle/Dalmatien et CP/Licorne, petits quiz hors ligne, voix TTS Android, profils locaux simples, étoiles, histoires et écran parents de démonstration.

## Important
Ce projet est une base/prototype et non le jeu complet prêt à publier. Le catalogue d'exercices est encore limité ; le contrôle parental n'est pas protégé par code PIN ; les activités de tracé, glisser-déposer, puzzles, mémoire avancée, illustrations/animations originales et voix enregistrées restent à développer et tester. La disponibilité d'une compilation GitHub ne garantit pas à elle seule le bon fonctionnement sur tous les appareils.
